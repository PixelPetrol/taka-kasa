# TAKA KASA — makieta

Klikalny prototyp GUI kasy na ekran 10,1″ (1280 × 800).

- **Makieta w przeglądarce:** https://pixelpetrol.github.io/taka-kasa/
- **Aplikacja Android (APK):** https://pixelpetrol.github.io/taka-kasa/taka-kasa.apk — Android 7.0+, poziomo, pełny ekran, działa offline.

Kasjerzy demo: PIN `1234`. Dane są przykładowe.

To repozytorium zawiera tylko zbudowaną stronę. Kod źródłowy jest w repozytorium prywatnym.
